- 🛰️ **[stashy](https://github.com/shivraj-S-bhatti/stashy)** - Geospatial ingestion fabric with agentic frontier expansion, adaptive queue scheduling, and benchmarkable infra metrics.
- 🤖 **[RobotArmSegmentation](https://github.com/shivraj-S-bhatti/RobotArmSegmentation)** - Robot-arm segmentation benchmark for DROID-style episodes with evaluation tooling and bootstrap labeling flows.
- 🧪 **[rl_finetuning](https://github.com/shivraj-S-bhatti/rl_finetuning)** - New March 2026 repo scaffold reserved for reinforcement learning fine-tuning experiments.
- ⚡ **[cuda_kernel](https://github.com/shivraj-S-bhatti/cuda_kernel)** - New March 2026 repo scaffold reserved for lower-level CUDA systems experiments.
